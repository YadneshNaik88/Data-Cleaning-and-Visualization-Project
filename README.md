# Data Cleaning and Visualization Project

## Overview
This project demonstrates the process of cleaning, preprocessing, and visualizing a raw dataset using Python. The Titanic dataset was used to identify missing values, remove duplicates, detect outliers, and generate meaningful visualizations.

## Objectives
- Handle missing values
- Remove duplicate records
- Detect and handle outliers
- Perform exploratory data analysis (EDA)
- Create visualizations to understand the dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Structure

## Visualizations
The project includes:
- Gender distribution
- Age distribution
- Survival count
- Fare distribution
- Box plot for outlier detection

## Output
- Cleaned dataset (`cleaned_titanic.csv`)
- Jupyter Notebook with complete data cleaning and visualization process

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/YadneshNaik88/Data-Cleaning-and-Visualization-Project.git
   ```

2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook:
   ```
   notebooks/project.ipynb
   ```
